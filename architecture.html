DeBait Follow the evidence.

One DeBait agent owns a self-directed loop: observe evidence, reason, decide whether to read more or intervene, gate each action through policy, verify by re-reading provider state, and adapt until contained or escalated. The loop is implemented; provider actions in this diagram are illustrative—no API calls.
